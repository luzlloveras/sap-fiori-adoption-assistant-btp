# Info to Request from Basis or Security – Fiori Launchpad and Authorization

## When you need basis/security input (401, 403, apps not visible)

For HTTP 401/403 in Fiori Launchpad, OData 401/403, or apps not visible in Launchpad, ask basis or security for structured data.

## Access details

Ask for the exact user ID, client, and system alias used for testing. Confirm no client mismatch.

## Role details

Request the business role name, the generated PFCG role name, and the transport history. Relevant for apps not visible and authorization errors.

## Diagnostic data

Ask for authorization trace results (e.g. SU53), /IWFND/ERROR_LOG for OData, and any Launchpad or ICF error logs. Include HTTP 401/403 and OData service name if applicable.

## Escalation information

- Provide user, client, system alias, role names, and symptom (e.g. OData 401 error, Launchpad 403, apps not visible).
